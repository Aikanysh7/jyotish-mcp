# Privacy Policy — Jyotish MCP Server

_Last updated: 2026-08-09_

## What this service does

The Jyotish MCP server performs astronomical/astrological computations
(Vedic birth chart, planetary periods, transits) from birth data supplied
in each request: date, time, place coordinates or city name.

## Data we process

- Birth date, time, coordinates/city passed in tool calls.

## Data we store

- **None.** All computations are performed in memory per request.
  No birth data is written to disk, logged, or transmitted to third parties.
  The service keeps no user accounts and sets no cookies.

## Hosting

The service runs as a stateless web service. Standard infrastructure-level
access logs of the hosting provider (IP address, timestamp, request path)
may apply; see your hosting provider's policy.
