# Деплой удалённого MCP-сервера и подключение к Claude

Сервер поддерживает два режима: локальный stdio (см. README.md) и удалённый
HTTP. Этот файл — про удалённый: сервер живёт в облаке, а любой пользователь
Claude подключает его по ссылке за минуту, без Python и терминала.

## Вариант А: Render.com (бесплатно, самый простой)

1. Создайте аккаунт на https://github.com и https://render.com (вход через GitHub).

2. Создайте новый репозиторий на GitHub (например, `jyotish-mcp`, можно приватный)
   и загрузите в него все файлы этой папки. Проще всего через веб-интерфейс:
   Add file → Upload files → перетащите файлы → Commit.

3. В Render: **New → Web Service** → выберите ваш репозиторий.
   Render сам увидит Dockerfile. Настройки:
   - Instance type: **Free**
   - всё остальное по умолчанию → **Deploy Web Service**

4. Через пару минут сервис поднимется, и вы получите адрес вида
   `https://jyotish-mcp.onrender.com`. Ваш MCP-эндпоинт:

   ```
   https://jyotish-mcp.onrender.com/mcp
   ```

Нюанс бесплатного тарифа Render: после 15 минут без запросов сервис
засыпает, первый запрос будит его ~30–50 секунд. Для личного пользования
это терпимо; для публичного продукта возьмите платный инстанс (~$7/мес)
или Railway/Fly.io.

## Вариант Б: локальный Docker (для проверки)

```bash
docker build -t jyotish-mcp .
docker run -p 8000:8000 jyotish-mcp
# эндпоинт: http://localhost:8000/mcp
```

## Подключение в Claude

**Веб/десктоп Claude:** Settings → **Connectors** → **Add custom connector** →
вставьте URL эндпоинта (`https://…/mcp`) → Add. Готово: инструменты jyotish
появятся в любом чате, где включён этот коннектор. То же самое сможет сделать
любой человек, которому вы дадите ссылку.

Проверка: напишите в чат «Разбери карту: 3 мая 1986, 09:15, Бишкек».

## Важно знать

- **Аутентификации нет**: любой, кто знает URL, может пользоваться сервером.
  Данные нигде не сохраняются (сервер ничего не пишет на диск и не логирует
  данные рождения), но для публичного запуска стоит добавить OAuth —
  Claude поддерживает авторизацию для кастомных коннекторов.
- **Каталог коннекторов Anthropic**: чтобы коннектор «появился у всех»,
  удалённый сервер подаётся на ревью Anthropic (нужны: стабильный хостинг,
  политика конфиденциальности, страница поддержки). Файл PRIVACY.md —
  готовая заготовка политики.
- Организациям на Claude Team/Enterprise админ может включить коннектор
  сразу для всей команды: Admin settings → Connectors.
